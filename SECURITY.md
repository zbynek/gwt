# Security policy

Security issues may be reported against the latest stable version of GWT (2.13.1)
or against the current development version (`SNAPSHOT-HEAD`).

Issues where a developer's machine maybe compromised by running GWT compiler or development server
on malicious code are not considered security vulnerabilities.

If you found a vulnerability, please use GitHub [Security Advisories](https://github.com/gwtproject/gwt/security/advisories)
to report it confidentially.
